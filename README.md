# OBIPTV v1

Android TV / Android için Jetpack Compose başlangıç projesi.

## İlk sürüm
- OBIPTV ana ekranı
- Live TV, Movies, Series, Multiscreen, Continue Watching, Settings kartları
- TV kumandası odak desteği
- Yatay ekran
- Android TV launcher desteği

## Açma
1. Android Studio ile bu klasörü açın.
2. Gradle Sync tamamlanmasını bekleyin.
3. Android TV emülatörü veya cihaz seçin.
4. Run ile çalıştırın.
5. APK: Build > Build App Bundle(s) / APK(s) > Build APK(s)

Not: v1 henüz gerçek yayın kaynağı içermez. Sonraki aşamada yalnızca kullanıcının erişim hakkına sahip olduğu M3U/API kaynakları ve Media3 oynatıcı eklenebilir.
